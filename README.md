# ATA Platform v2

Clickable prototype for the Africa Tech Academy platform — a single self-contained `index.html` (fonts and assets inlined) with a page switcher across:

**Public site** — Home · Programs · Program Detail · Course Marketplace · Course Detail · Testimonials · Resources Hub · Become a Facilitator
**Portals** — Facilitator Wizard · Facilitator Dashboard · Admin Review

## Run it
Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

Works as-is on GitHub Pages (Settings → Pages → deploy from `main`, root).
