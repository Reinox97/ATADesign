# Udohbé Candles

Animated build of the Udohbé candle store Figma file (copy kept as designed). One self-contained `index.html` with hash routes:

`#home` · `#all-candles` · `#product` · `#checkout` · `#order-placed` · `#contact` · `#faq`

Images live in `img/`. Serve the folder (`npx serve .`) or open `index.html` directly.
